# Разбор пакета `modtree` (Виртуальная файловая система)

Пакет `modtree` предназначен для парсинга дескрипторов `.module` и построения единого виртуального дерева файлов (VFS) для модификаций *Dawn of War*. Он объединяет разрозненные данные из физических папок на диске и архивов `.sga`, выстраивая их в иерархию с учетом зависимостей и приоритетов перекрытия файлов.

* Читать на других языках: [English](README.md)

## Слияние и приоритеты (Virtual File Tree)

* Все ресурсы текущего мода, требуемых модификаций (Required Mods) и базовой игры проецируются в единую виртуальную файловую систему с общим корнем `Data`.
* Загрузка источников подчиняется строгому порядку приоритетов:
  * **Текущий мод (`KindThisMod`):** Наивысший приоритет (от 0).
  * **Требуемые моды (`KindReqMod`):** Средний приоритет (от 15000).
  * **Базовая игра (`KindEngine`):** Низший приоритет (30001).
* При конфликте имен файлов (дубликатах) выигрывает тот файл, чей источник был зарегистрирован первым (с наивысшим приоритетом). При этом содержимое папок с одинаковыми именами корректно объединяется (merge).

## Оптимизация и многопоточность

* Регистрация источников выполняется строго последовательно, чтобы сохранить детерминированный порядок перекрытия файлов.
* Непосредственный обход файловой системы и чтение таблиц `.sga` (`buildPending`) выполняются параллельно с использованием пула горутин (`runtime.NumCPU()`).
* Такое разделение критически ускоряет загрузку, поскольку обход тысяч директорий и чтение индексов архивов занимают большую часть времени при старте приложения.

## Индексация и поиск

* Индекс файлов по базовому имени строится лениво (при первом обращении) и защищен мьютексом для предотвращения состояния гонки при параллельном доступе.
* Пакет реализует продвинутый регистронезависимый поиск по нескольким словам:
  * Каждое слово из запроса должно присутствовать либо в имени файла, либо в пути к нему.
  * Результаты поиска ранжируются: точные совпадения в имени файла ценятся выше (к совпадениям только в пути папки применяется штраф `folderScoreBias = 100`).
  * При равном счете файлы сортируются по приоритету источника (текущий мод всегда выше).
* Встроенная фильтрация по расширениям через `SearchKind` (RGD, Lua, FDA, ART/текстуры, WHM).

## Редактирование (Overlay) и Парсинг

* Пакет поддерживает режим "оверлея" для сохранения изменений в файлы мода. Метод `WriteOverlayFile` сохраняет файл на диск в правильную физическую директорию текущего мода (создавая нужные папки) и моментально внедряет его в виртуальное дерево (upsert).
* Встроенный парсер файлов `.module` читает INI-подобный синтаксис, извлекая массивы `DataFolder.N`, `ArchiveFile.N` и `RequiredMod.N`.
* Парсер автоматически разрешает динамические пути (динамики Corsix), заменяя токены вроде `%LOCALE%` или `%TEXTURE-LEVEL%` на их реальные текстовые значения.
