# Разбор формата файлов `.whe` (Relic Chunky)

Файлы `.whe` используются в движке Relic для хранения визуальных эффектов (FX), звуковых событий и их привязки к анимациям моделей. Формат базируется на иерархической структуре чанков (Relic Chunky).

* Читать на других языках: [English](README.md)

## Логика работы
Связывание эффектов с юнитом происходит в три этапа:
1. **Чертёж (Blueprint):** Файлы `attrib/ebps/**.lua` привязывают игровые триггеры к именованным событиям.
2. **Файл событий:** Имя события ссылается на файл `.events` (находится в `art/events`).
3. **Привязка к маркеру:** Файл `.events` указывает, какой `.lua` эффект проигрывать и на каком маркере модели (маркеры объявляются в чанке `DATAMARK`).

## Основные секции (Чанки)

### 1. `DATAEVNT` (Определения событий)
* Располагаются внутри папки `FOLDEVCT`.
* Имя чанка соответствует имени события.
* Хранят пары ключ-значение (например, путь `fx`, привязки к маркерам, параметры вроде `random_set`).
* **Звуковые события:** Отличаются префиксом `sound_` в имени. Вместо эффектов содержат путь к звукам (относительно `data/sound`). Если полезная нагрузка чанка состоит из 4 нулевых байт — это "беззвучное" событие. Поддерживается токен `%terrain%` (заменяется на dirt, sand, grass, rock или water в зависимости от поверхности).

### 2. `DATAMTON` (Таймлайны анимаций)
* Располагаются внутри папки `FOLDMTRE`.
* Управляют тем, какие события и в какую секунду срабатывают при воспроизведении конкретного клипа (анимации).
* Обычные события привязаны к секундам, но есть два исключения:
  * `-1` — событие срабатывает при *входе* в анимацию.
  * `MAX_FLOAT` — событие срабатывает при *выходе*.
* В конце чанка хранится хвост (Motion Tail), описывающий параметры воспроизведения: зацикливание, задержки, переходы и модификаторы.

### 3. `DATAACTS` (Слой действий)
* Слой логики, находящийся над таймлайнами. Управляет тем, какие таймлайны воспроизводить и какие под-действия вызывать.
* Решения принимаются на основе цепочки условий, аналогичной `if / else if / else / always`. В коде файла эти типы условий представлены числами: `0`, `1`, `2` и `3` соответственно.
