# DoW Mod Studio

> [English](README.md) | Русский

Настольная программа (Go + Gio UI) для моддинга **Warhammer 40,000: Dawn of War — Definitive Edition**.
Открывает `.module` файлы, собирает единое дерево файлов мода из всех источников (сам мод, зависимые моды,
архивы движка `.sga`) и даёт смотреть, слушать, редактировать и пересобирать их содержимое — от таблиц
юнитов `.rgd` до 3D-моделей `.whm`, эффектов `.whe` и звука `.fda`.

Программа читает и пишет форматы игры напрямую: сохранение идёт в папку самого мода (overlay), пакетирование —
в архивы SGA v2 по образцу Relic `CSgaCreator`, референсы между файлами индексируются и проверяются на битость.

## Возможности

* Просмотр и правка RGD-таблиц (юниты, здания, оружие, способности, сквады) с переходами по ссылкам.
* Окно **Object** — редактор объектов мода: свойства юнита, оружие, способности, сквады, связи,
  битые ссылки, таймлайны эффектов и 3D-вьюпорт с редактированием анимаций и костей.
* 3D-просмотрщик `.whm`: скелет, анимации, маркеры, превью эффектов `.whe` и звуков, экспорт в `.sgm`.
* Аудиоплеер для `.fda` и `.wav` с волной, перемоткой и экспортом в WAV.
* Просмотрщик текстур (`.dds`, `.rsh`, `.rtx`, `.tga`, `.png`, `.jpg`, `.bmp`) с мип-уровнями.
* Текстовый редактор с подсветкой для `.lua`, `.txt`, `.ai`, `.scar`, `.rat`, `.con` и др. (список настраивается).
* Локализация: выбор языка, разрешение `$id` по таблицам `.ucs`, переход к строке и правка текстов.
* Freeze/Unfreeze юнитов и зданий с записью журнала отката.
* Пакетирование мода в `.sga` (SGA v2) и распаковка архивов на просмотр.
* Поиск файлов по имени с фильтрами по типам, история «Недавние моды», корзина, автосохранение сессии.

## Системные требования

* Windows (основная платформа: Vulkan-рендер, ассоциация `.module`). На других ОС программа
  собирается и работает на программном рендере, но без аппаратного 3D и ассоциации файлов.
* Установленная игра **Dawn of War Definitive Edition** (стандартные пути Steam подставляются в диалог открытия).

## Быстрый старт

1. Запустите `dow-mod-studio.exe` (или соберите его — см. [Сборка](#сборка-из-источников)).
2. `File → Open Module…` — введите папку игры или выберите `.module` из списка (диалог сканирует папку на `.module`).
3. Слева появится дерево мода, вкладка **Module** откроется автоматически. Двойной щелчок по файлу открывает
   вкладку с просмотрщиком, соответствующим типу файла.
4. Кнопка **Object** в правом верхнем углу открывает окно объектов — основной редактор юнитов и зданий.
5. `Mod → Save` записывает накопленные правки RGD/текста в папку мода; `Mod → Pack SGA…` собирает архив.

## Интерфейс

Окно состоит из:

* **Строки меню** (сверху): меню `File`, `Mod`, `Help`, справа — выбор языка, кнопка **Object** и поле поиска.
* **Панели вкладок**: вкладка `Module` (дерево мода) плюс открытые файловые вкладки. Колесо прокручивает
  панель вбок, правый щелчок по вкладке — контекстное меню («закрыть все вкладки»), крестик закрывает вкладку.
* **Трёхпанельной области**: слева дерево мода, в центре содержимое (дерево RGD / плеер / модель), справа
  панель **Properties**. Панели раздвижные, ширина запоминается.
* **Статусной строки** (снизу): результат последнего действия, путь открытого файла, ошибки.

Вкладка **Module** и файловые вкладки независимы: дерево мода остаётся на месте, пока вы переключаетесь
между открытыми файлами.

## Меню Mod

| Пункт | Что делает |
|---|---|
| `Save` | Записывает накопленные правки активной вкладки (RGD или текст) в папку мода через overlay: файл появляется в `Data\…` папки текущего мода, и дерево обновляется само. |
| `Export File` | Копирует файл из архива SGA или родительского мода в папку текущего мода, делая его «своим» и редактируемым. Недоступно, если файл уже есть в папке мода. |
| `Pack SGA…` | Пакует все файлы текущего мода в архив SGA v2 (`<ModFolder>\<FileMap>.sga`, при существующем файле — `…_packed.sga`) и добавляет запись об архиве в `.module`. |
| `Extract SGA…` | Диалог со списком архивов SGA мода: распаковывает выбранные на просмотр/редактирование. |
| `Burn Mod` | Заглушка (пока выводит сообщение в статус-строку). |
| `Module Settings…` | Заглушка (пока выводит сообщение в статус-строку). |

| Пункт | Что делает |
|---|---|
| `About DoW Mod Studio`, `Documentation`, `Check for Updates` | Заглушки: выводят сообщение в статус-строку. |
| `Open log folder` | Открывает папку с журналом работы программы. |

## Элементы строки меню справа

* **Выбор языка** — выпадающий список языков, найденных в файловых таблицах `.ucs` (папка игры и мода).
  Язык — глобальная настройка: в нём разрешаются все `$id` локализованных строк в RGD и окне объектов.
* **Object** — кнопка, открывающая окно объектов (см. ниже). Активна, пока окно открыто.
* **Поиск** — поле поиска файлов по имени с выпадающей панелью результатов над деревом. Фильтры-чипы:
  `All`, `RGD`, `Lua`, `FDA`, `ART` (текстуры: `.art/.rsh/.dds/.tga/.texture`), `WHM`. Стрелки и Enter
  выбирают попадание; щелчок открывает файл. Повторный ввод текста переищет, закрытая панель остаётся
  свёрнутой, пока запрос не изменится.

## Дерево мода (левая панель)

Единое дерево всех доступных файлов мода. Цвет подписи показывает источник:

* **красный** — файлы самого загруженного мода;
* **синий** — файлы зависимых (required) модов;
* **серый** — файлы движка (архивы игры).

Функции:

* раскрытие/свёртывание папок, стрелки с клавиатуры навигируют, `Enter` открывает файл, `Delete` удаляет
  (с подтверждением; удаляется только файл текущего мода);
* правый щелчок по файлу — меню: **Duplicate** (копия файла в моде) и **Delete** (в корзину);
* удалённые файлы попадают в корзину `%AppData%\DoW Mod Studio\recycle`, откуда их можно вернуть;
* дерево автоматически обновляется при внешних изменениях файлов мода (fsnotify) — не нужно перезагружать мод;
* неразрешающиеся ссылки в RGD подсвечиваются красным.

## Вкладки файлов и просмотрщики

Тип вкладки выбирается по расширению файла:

| Формат | Вкладка | Возможности |
|---|---|---|
| `.rgd` | RGD-редактор | Слева дерево таблицы (сворачивание, навигация стрелками), справа **Properties**: правка скалярных значений (числа, строки, bool), ссылок на другие `.rgd` (с переходом к файлу по Enter), подсказки значений. `Alt`+щелчок по локализованной строке (`$id`) открывает её в `.ucs`. Правки копятся до `Mod → Save`. |
| `.lua`, `.txt`, `.ai`, `.scar`, `.rat`, `.con`, … | Текстовый редактор | Подсветка синтаксиса, «грязный» флаг, сохранение через `Mod → Save`. Список расширений настраивается в Settings; файлы чужого именования из этого списка открываются здесь же. |
| `.ucs` | Текстовый редактор (только чтение) | Файлы локализации живут вне мода, поэтому вкладка read-only и говорит об этом. Открывается из окна локализации. |
| `.fda` | Аудиоплеер | Play/Pause, стоп, перемотка ±10/±30 с, ползунок позиции, повтор, громкость 0–200 %, кликабельная волна, `Export WAV`. Свойства FDA: частота, каналы, длительность. |
| `.wav` | Аудиоплеер | Play/Stop, повтор, громкость, волна, конвертация/экспорт. |
| `.jpg/.jpeg/.png/.bmp/.tga/.dds/.rtx/.rsh` | Просмотрщик изображений | Зум, вписывание, переключение мип-уровней (DDS/RSH/RTX), свойства изображения справа. |
| `.whm` | 3D-просмотрщик | Модель с материалами `.rsh`, список анимаций и воспроизведение (play/pause, шаг кадра вперёд/назад, сброс), скелет, текстуры, зум, поворот/зеркальность UV, превью эффектов и звуков из `.whe` (кнопка FX, масштаб эффектов, угли поворота X/Y/Z), кнопка `Convert to SGM` для экспорта модели в `.sgm`. |

Справа на любой вкладке — панель **Properties**: сведения о файле, свойства FDA/WAV/модели/изображения
или свойства выбранного узла RGD + **Table Children**.

## Окно Object (кнопка «Object»)

Главный редактор объектов мода. Сверху — выбор расы и юнита (со значками и именами из локализации),
кнопки **New Unit** и **New Building** (пишут новый `.rgd` из шаблона, собранного по образцу игровых файлов,
сразу в мод — без перезагрузки), **Freeze** / **Unfreeze**. Слева — список разделов, в центре — содержимое
раздела, справа — свойства выбранной строки.

Разделы:

* **Unit info** — скалярные свойства юнита/здания (здоровье, броня, стоимость, иконки, локализованные названия
  и т. д.). Строка редактируется в правой колонке (Save / Revert / Open RGD); локализованные значения
  открываются в языке, выбранном в строке меню.
* **Weapons** — список оружия юнита с переходом к свойствам каждого.
* **Abilities** — список способностей аналогично.
* **Squads** — сквады, в которые входит юнит (связь строится сканом всех сквадов в фоне), с переходом к файлу сквада.
* **Links** — обе стороны связей: над чертой — на что ссылается этот объект (оружие, способности, постройка и т. д.),
  под чертой — что ссылается на него. Роль, слот, цель; неразрешившиеся ссылки помечены красным. Freeze читает
  именно этот список.
* **Frozen** — юниты и здания, вынесенные из мода в проект; показывает, что и где было очищено, и позволяет вернуть (Unfreeze).
* **Problems** — все битые ссылки мода: ссылки на несуществующие файлы.
* **Events** — таймлайны `.whe` выбранной модели: определения событий (DATAEVNT) и таймлайны (DATAMTON), которые
  их запускают. Форма добавления события (имя, момент, FX, звук, маркер), правка полей события (Enter или Set),
  Copy/Paste через буфер истории, удаление, сохранение `.whe` (Save/Revert). Аудиослушивание: звук события или
  последовательность звуков таймлайна с плейхедом и перемоткой; FX перерисовываются в вьюпорте.
* **Viewport** — 3D-модель юнита: список анимаций, камеры, playback, списки маркеров и костей. Редактирование
  ключевых кадров кости: добавление позиций/поворотов на плейхед, вставка ключа до/после выбранного, удаление,
  сдвиг по кадрам, зеркалирование по осям X/Y/Z, ползунки угла −180…180°, Undo, запись в `.whm` (Save).
  «Import frame's timeline» — копирование ключей из таймлайна другого `.whm` (Copy/Replace).

## Freeze / Unfreeze

**Freeze** выносит юнит или здание из мода, не удаляя его: `.rgd`-файлы перемещаются в папку проекта
(`%AppData%\DoW Mod Studio\Projects\<Мод>\Units`), игра их больше не видит, но файлы сохранены для просмотра.
Перед перемещением программа находит все ссылки на объект (например, оружие могут использовать сотни юнитов),
очищает их и записывает исходные значения в `dependencies.json` в папке `Units` проекта. **Unfreeze** читает
журнал и всё возвращает назад. Порядок таков, что ни одна правка не выполняется до записи данных для отката.

## Поиск по файлам

Поле в строке меню (см. выше). Поиск по имени файла по всему объединённому дереву (мод + зависимости + движок),
с фильтрами по типам и ранжированием (совпадение имени файла выше совпадения папки).

## Локализация

* Строка `.ucs` читается из папки игры и папки мода; список языков строится из найденных файлов.
* Значения вида `$id` в RGD и окне Object разрешаются в текст выбранного языка.
* `Alt`+щелчок по локализованной строке — переход к строке в `.ucs` (вкладка только для чтения);
  `Alt+Ctrl`+щелчок (или щелчок по неразрешённому id) — диалог правки/создания строки локализации с записью
  в `.ucs` мода.

## SGA

* `Mod → Pack SGA…` — упаковка файлов текущего мода в архив SGA v2 с обновлением `.module`.
* `Mod → Extract SGA…` — распаковка выбранных архивов мода на диск для просмотра/редактирования.
* Архивы движка и родительских модов читаются на месте и отображаются в дереве (цвета выше).

## Настройки (File → Settings)

* **Тёмная/светлая тема** — применяется сразу, отмена возвращает прежнюю.
* **Графический рендер**: `Vulkan` (по умолчанию), `Software` — применяется при следующем запуске
  (через переменную окружения `DOW_GPU_API`). Программный рендер — запасной путь от сбоев аппаратного рендера.
* **Папка игры** — от неё зависят список языков и таблицы локализации.
* **Форматы текстового редактора** — список расширений через запятую (`.lua, .txt, .mydsl`); пустой список
  возвращает значения по умолчанию.

## Хранение данных

Всё личное лежит в `%AppData%\DoW Mod Studio\`:

```
state.conf   — состояние сессии (тема, рендер, папка игры, открытая мода и вкладки, язык,
               раскрытые папки, выбор в окне Object); сохраняется автоматически
recycle\     — корзина удалённых файлов мода
Projects\<Мод>\Units\                  — вынесенные freeze'ом юниты/здания
Projects\<Мод>\Units\dependencies.json — журнал очищенных при freeze ссылок
```

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `↑` `↓` `←` `→` | Навигация и сворачивание/разворачивание в дереве файлов и дереве RGD |
| `Enter` | Открыть выбранный файл / перейти по ссылке RGD |
| `Delete` | Удалить выбранный файл мода (с подтверждением) |
| `Esc` | Закрыть контекстное меню |
| Колесо на панели вкладок | Боковая прокрутка вкладок |
| `Alt`+щелчок / `Alt+Ctrl`+щелчок по локализованной строке | Переход к `.ucs` / правка строки локализации |

В окне Events: `Ctrl`+щелчок — множественный выбор строк, `Shift`+щелчок — диапазон; в Pose-баре костей
те же модификаторы работают с ключевыми кадрами.

## Командная строка и ассоциации

Программа открывает `.module`, переданный как аргумент (`dow-mod-studio.exe mymod.module`), — так работает
двойной щелчок после ассоциации. Служебные флаги:

```
--register     / --register-assoc   зарегистрировать ассоциацию .module
--unregister   / --unregister-assoc снять ассоциацию
--assoc-status / --status           показать состояние ассоциации
```

Вспомогательные утилиты в `cmd/`: `audiotest` (проверка аудиотракта) и `sgafind` (поиск по SGA из консоли).

## Сборка из источников

Требуется Go 1.27.1. На Windows:

```
d_build_windows.bat
```

Скрипт собирает `dow-mod-studio.exe` (`-trimpath -ldflags "-s -w -H windowsgui"`).
Обычный `go build ./...` создаёт консольный бинарник и не обновляет проверяемый в репозитории `.exe` —
для рабочего бинарника используйте скрипт с явным `-o`.

Проверка:

```
go test ./...
go build ./...
```

> **Примечание для чистого клона:** `go.mod` содержит `replace`-директивы на локальный форк Gio
> (путь вида `C:/Users/…/gio`), включая `vulkan-go` и форк шейдеров. Чтобы собрать у себя,
> поправьте эти пути под свои локальные клоны форка (или уберите `replace`, используя апстрим Gio —
> аппаратный Vulkan-рендер при этом может быть недоступен).

## Структура репозитория

Код приложения — в корне (пакет `main`, файлы по подсистемам: `unit_*.go`, `viewer_*.go`, `fx_*.go`,
`locale_*.go`, `fda_*.go`, `rgd_*.go`, `sga_*.go`, `freeze*.go`, `graph_ui.go`, …). Форматы игры инкапсулированы
в `internal/`:

| Пакет | Назначение |
|---|---|
| `internal/modtree` | парсинг `.module`, объединённое дерево источников (мод / зависимости / движок), поиск |
| `internal/rgd` | бинарный формат RGD: чтение, запись, типы, ссылки |
| `internal/fda` | кодек аудио Relic FDA (декод, ресемпл, кодирование WAV) |
| `internal/wav`, `internal/audioplayer` | WAV и проигрывание с буферизацией |
| `internal/whm` | модели `.whm`, скелет, анимации, экспорт `.sgm` |
| `internal/whe` | формат эффектов `.whe`: события и таймлайны |
| `internal/fx` | симуляция и рендер эффектов (спрайты, ленты, лучи), Lua-определения, звуки |
| `internal/sga` | чтение архивов SGA; запись SGA v2 — в `sga_pack.go` приложения |
| `internal/raster` | декодеры изображений: DDS (включая BC7), TGA, RSH, RTX, PNG/JPEG/BMP |
| `internal/3d_engine`, `internal/3d_viewer` | программный и аппаратный рендереры, камера, оси |
| `internal/chunky` | chunked-контейнер игры |
